# Example JSON Plans

Below are real-world example benefit plans structured using the **Benefit Plan Standard v1.1.0**. Every example was generated by a real extraction pipeline from a public SBC and verified value-by-value against the source document; the source PDFs ship alongside the examples in `examples/sources/`.

These examples help developers, carriers, and vendors understand how to implement the schema correctly.

👉 **View the complete example library on GitHub:**  
https://github.com/Benefit-Plan-Standard/benefit-plan-schema/tree/main/examples

## Included Examples

The following carriers currently have example JSON plans:

- Aetna (PPO 1500 and PPO 5000)  
- Ambetter (Health Net of CA, Silver 94 HMO)  
- Blue Cross (Florida Blue BlueOptions 505)  
- Cigna (Open Access Plus)  
- GatorCare (Prime EPO, self-funded)  
- Kaiser Permanente (Gold 80 HMO)  
- UnitedHealthcare (Choice Plus HSA Gold, POS)  

Each plan demonstrates:

- Standardized `plan_id` fields  
- Network tiers  
- Deductibles & copays  
- Accumulators  
- Medical benefits  
- Limits and special rules  
- Source references
